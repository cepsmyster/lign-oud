# Lign

A landing page study for an invented oud perfume house. One WebGL2 canvas behind the page: a ray-traced crystal flacon, oud oil, a gold word on the wall, and smoke from a burning agarwood chip run by a fluid solver. No libraries, no image files. The only network request is Google Fonts.

Open `index.html`, or visit the GitHub Pages site for this repository.

## Controls

- Move the pointer: camera, key light and smoke follow.
- Click: a puff from the ember. Drag sideways or press the left and right arrows: turn the flacon.
- Scroll, Page Up, Page Down, Home, End: move between sections.
- `?s=0..1` sets the scroll position, `?t=seconds` freezes time, `?view=hero|wood|forests|batch|notes|sizes|footer` jumps to a pose.

Lign is not a real brand. The forests are invented.
